# ACTS.md — Muse closes the gap

Assignment 2, Part 2 film: how Muse would do the gap analysis — three
columns (they ask / I have / to build), five rows, a second comparison
column, and the Madison project as the gap-closer.

**Exact title:** Muse closes the gap

**Core promise:** By the end, the viewer can build the table: read the
postings together, extract what they ask for, sort it into have vs.
to-build, and name the one project that closes the biggest gap.

**Structure:** Four acts.

- Act I — Name the gap (2 beats): the three gaps from Part 1; the second
  comparison column.
- Act II — The five rows (5 beats): teaching material; on camera; hands-on
  depth; community; AI workflows.
- Act III — The build list (2 beats): the four things to make; the Madison
  project.
- Act IV — The honest column (1 beat): link, don't rebuild; the table stays
  public.

**Tone:** working session. A table being filled in, not a lecture.

**What this film is not:** not a résumé rewrite; not "you're already
qualified." It's the build list.

**Source facts:**
- Part 1 gaps (`assignment-2/part-1-dream-job.md`): never shipped a design
  system in Figma; public speaking at meetups/conferences; travel up to 25%.
- Second column (`part-1-appendix-seven-boards.md`): the gap analysis gets a
  second column — Webflow's Senior Developer Educator — to compare against.
- Five rows (`advocate/README.md`, "What the postings ask for, and what I
  will build here"):
  1. Written/visual/video teaching material about the product → have:
     hundreds of course videos, deep-explainer pipeline, Coursera MOOC →
     build: tutorials about *their* product (Figma design systems + MCP
     book, Webflow University-style build-along, Notion API walkthrough).
  2. On camera, own voice → have: lecture recordings, EDGE studio work →
     build: 3–5 minute on-camera sample, no synthetic narrator, one
     design-system idea.
  3. Hands-on depth in the tool → have: Figma boards in class, MS in
     Information Design → build: one shipped Figma design system (tokens,
     Dev Mode handoff) + one production Webflow site, both open.
  4. Community and public speaking → have: 150+ Fellows, AI Bootcamp 500+,
     conference talks → build: speaking reel from existing recordings +
     talk list.
  5. AI-assisted workflows, MCP, evals → have: Prompt Engineering &
     Computational Skepticism courses, 25+ deployed course bots → already
